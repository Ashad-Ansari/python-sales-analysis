# Python Sales Analysis

## Project Overview

This project explores sales and profit data using Python to identify business trends, understand profitability, and generate useful insights through data analysis and visualization.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset contains 9,994 sales records and 13 columns, including sales, profit, quantity, discount, category, sub-category, region, and city.

## Project Objectives

- Analyze overall sales and profit.
- Compare sales and profit across product categories.
- Identify top-performing cities.
- Investigate the relationship between discounts and profit.
- Visualize business trends using charts.

## Data Cleaning

- Checked dataset structure and data types.
- Identified duplicate records.
- Removed duplicate rows before analysis.

## Analysis & Visualizations

- Overall sales and profit analysis
- Category-wise sales and profit
- Top 10 cities by sales and profit
- Discount and profitability analysis
- Bar charts, scatter plots, box plots, and correlation heatmap

## Key Skills Demonstrated

Data cleaning, exploratory data analysis (EDA), data aggregation, business analysis, and data visualization.
